프롬프트 복습 노트 · 배포용 파일

index.html       시안 선택 첫 화면
library.html     시안 A · 프롬프트 서재 (검색·즐겨찾기)
cheatsheet.html  시안 B · 프롬프트 한 장 정리
practice.html    시안 C · 프롬프트 연습장 (빈칸 채우기·진도)

모든 파일은 서로 독립된 한 파일짜리 웹페이지입니다. (글꼴만 Google Fonts에서 불러옵니다)
하나만 쓰고 싶으면 그 파일 이름을 index.html로 바꿔서 올리면 됩니다.

[배포 방법 1] Netlify Drop
  app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓기 → 바로 주소가 생깁니다.

[배포 방법 2] GitHub Pages
  새 저장소에 이 파일들을 올리기 → Settings → Pages → Branch: main / root → Save
  잠시 뒤 https://아이디.github.io/저장소이름/ 으로 열립니다.

[내 컴퓨터에서 보기]
  파일을 더블 클릭하면 브라우저에서 바로 열립니다.

참고: 즐겨찾기·진도·화면 테마는 보는 사람의 브라우저에만 저장됩니다.
